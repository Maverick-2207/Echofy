## Overview
Echofy is a **lightweight, browser-based music player** built with **HTML, CSS, and JavaScript**. It provides a **dynamic playlist system** allowing users to load albums, search songs, and play music with smooth controls. The app is **responsive** and optimized for static deployment platforms like **Netlify**, **Vercel**, or **GitHub Pages**.  

The design prioritizes **ease of use, performance, and interactivity**, giving users a modern music streaming experience without installing additional software.

---

## Features
- 🎵 **Dynamic Playlists** – Songs are loaded from a `songs.json` file for easy management.  
- 🔍 **Search Bar** – Quickly filter songs in the library by name.  
- ⏯ **Playback Controls** – Play, pause, next, previous, and seek functionality.  
- 🔊 **Volume Control** – Adjust the audio level seamlessly.  
- 🖼 **Album Cards** – Click on albums to instantly load entire playlists.  
- ✨ **Animated Song Titles** – Smooth scrolling animation for long track names.  
- 📱 **Responsive Design** – Fully functional on mobile and desktop browsers.  
- ⚡ **Optimized Deployment** – Works flawlessly on Netlify, Vercel, or GitHub Pages.  
- 💾 **Caching** – Already loaded playlists are cached for faster performance.  

---

## Future Enhancements

## Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/echofy-music-app.git
2. **Navigate into the folder:**
   ```bash
   cd echofy-music-app
3. **Open index.html in your browser or run a local server using VS Code Live Server or Python:**
   ```bash
   python -m http.server 8000
4. **Ensure SONGS/songs.json exists with your album/song structure.**

## Usage
-Click the play button to start streaming a song.
-Use next/previous buttons to navigate tracks.
-Drag the seekbar to jump to a specific part of a song.
-Adjust volume with the slider.
-Click on album cards to switch playlists.
-Type in the search bar to filter songs instantly.
